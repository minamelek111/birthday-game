# Birthday Game 

Birthday Game is a small 2D web-based game that I made as a birthday gift for my friend.

This is also my first time trying to develop a 2D game, so I used this project as a way to learn more about how interactive games work.

The game is made with HTML, CSS, and JavaScript. While working on it, I experimented with different interactions, scenes, sounds, and simple game mechanics.

Since this is my first project like this, there may be some glitches or problems. I am still learning, and this project was a good opportunity for me to experiment and improve my skills.

## Features

- Interactive gameplay
- Different scenes
- Sound effects
- Personalized messages
- A simple 2D game experience

## Built With

- HTML
- CSS
- JavaScript

## How to Run

You can download or clone this repository and open `index.html` in your browser.

## Why I Made This

I wanted to make something more interactive than a normal birthday message. Instead of just sending a text or a card, I decided to create a small game.

At the same time, this project gave me a chance to try 2D game development for the first time and learn by experimenting.

## What I Learned

While making this project, I learned more about:

- JavaScript interactions
- Managing different scenes
- Adding audio to a web project
- Connecting HTML, CSS, and JavaScript
- Creating a small interactive experience

This project is still a learning experience, and I hope to improve it and make more games in the future.
